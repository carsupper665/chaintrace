ChainTrace Frontend - Runtime and Module Requirements
======================================================

1. Required runtime
-------------------
Node.js >= 22.13.0
npm >= 10

Go, Python, and a local database are not required to build the frontend, but
the running application is unusable without the Go backend: sign-in and every
Investigation feature are backend-owned.


2. Install all frontend modules
-------------------------------
Run from the chaintrace-frontend directory:

npm install

The exact module versions are locked by package-lock.json.

5. Start the frontend in development mode
-----------------------------------------
npm run dev

Default local URL:
http://localhost:3000


6. Production build and local start
-----------------------------------
npm run build
npm run start


7. Backend connection
---------------------
CHAINTRACE_BACKEND_URL=http://localhost:7794

Copy .env.example to .env. Outside production an unset value falls back to
http://localhost:7794, the Go API's default port; a production build requires
it to be set explicitly.

There is no public chain-data fallback and no mock Agent response: without a
reachable Go backend the workspace redirects to /login.

Backend setup, required environment variables and the login journey:
../docs/local-development.md
