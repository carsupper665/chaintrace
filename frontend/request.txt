ChainTrace Frontend - Runtime and Module Requirements
======================================================

1. Required runtime
-------------------
Node.js >= 22.13.0
npm >= 10

Go, Python, and a local database are not required to run the frontend.


2. Install all frontend modules
-------------------------------
Run from the chaintrace-frontend directory:

npm install

The exact module versions are locked by package-lock.json.

5. Start the frontend in development mode
-----------------------------------------
npm run dev

Default local URL:
http://localhost:3000


6. Production build and local start
-----------------------------------
npm run build
npm run start


7. Optional backend connection
------------------------------
The frontend can start without the Go backend.

To enable the real AI Agent chat connection, configure:

CHAINTRACE_BACKEND_URL=http://localhost:<GO_BACKEND_PORT>

The Go backend must implement:

POST /api/v1/agent/chat

Without CHAINTRACE_BACKEND_URL, the chat middle API intentionally returns
HTTP 503 and does not generate mock model responses.
